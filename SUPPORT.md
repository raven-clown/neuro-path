# Getting help

- **Questions and ideas:** [Discussions](https://github.com/raven-clown/neuro-path/discussions)
- **Something broken:** [bug report](https://github.com/raven-clown/neuro-path/issues/new?template=bug_report.yml)
- **A step shows up in the wrong stage:** [stage detection issue](https://github.com/raven-clown/neuro-path/issues/new?template=stage_detection.yml)
- **Security problems:** see [SECURITY.md](SECURITY.md)

Before filing, check that you run Claude Code 2.1.286 or newer (`claude --version`) and that the pane opens with `/neuro`.
